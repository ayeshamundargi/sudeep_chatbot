1. Introduction & Privacy Philosophy

ClearMind AI ("we", "our", or "the Service") is built with a privacy-first architectural approach. We believe artificial intelligence tools should empower productivity without invasive surveillance or unnecessary personal data aggregation.

This Privacy Policy outlines what information is processed when you access ClearMind AI, how chat prompts are handled by backend AI providers, where conversation records are stored, and how you retain full control over your data.

2. Information Collected

We practice strict data minimization. Specifically:

  • Account Data: If running in guest or local mode, no account registration, names, email addresses, or phone numbers are requested or recorded.
  • Chat Messages: The text prompts you submit and the generated assistant replies.
  • Network & Operational Logs: Standard web server connection metadata (IP addresses, request timestamps, user-agent headers) strictly retained in volatile memory or transient logs for rate-limiting enforcement and security protection against abuse.

3. How Messages Are Processed & AI Provider Handling

To generate contextual answers, your messages are transmitted securely through HTTPS to our backend server and forwarded to the configured AI foundation model provider:

  • Google Gemini API (Google LLC): Subject to Google's API Terms and Developer Policies. Google does not use customer data submitted via paid enterprise API keys to train its models.
  • OpenAI API / Groq API: If configured by the deployment administrator, requests are processed under the respective provider’s enterprise API data privacy agreements.
  • Local Heuristic / Demo Engine: When running in Demo mode, messages are evaluated entirely on the local server without sending any data over external network boundaries.

We do not sell, rent, or monetize your prompt data or conversation histories to third-party data brokers or advertising networks.

4. Storage, Retention & Deletion Rights

Browser-Specific Storage: By default, your chat history is stored locally within your web browser using HTML5 localStorage. This means your conversation history never resides in our persistent backend database unless you explicitly sync or back up your profile.

Immediate User Deletion: You retain unilateral control over your conversation history. You can delete individual conversations using the trash icon in the sidebar or wipe all conversations instantly by selecting "Clear conversations". Clearing browser cookies and website storage also permanently removes all local records.

5. Cookies & Tracking Technologies

ClearMind AI does not use third-party tracking cookies, Google Analytics, social media widgets, or advertising trackers. Local browser storage is utilized strictly for essential technical state: preserving your active conversation, theme preference, and sampling settings.

6. Security Protections

We apply defensive engineering practices to safeguard application traffic and user interaction:

  • Strict Content Security Policy (CSP) headers via Helmet to prevent cross-site scripting (XSS).
  • DOM sanitization with DOMPurify prior to rendering any assistant markdown response.
  • Server-side secret isolation: API keys are strictly loaded in server environment variables and never exposed to the client.
  • Rate limiting per client IP to mitigate denial-of-service attempts.
