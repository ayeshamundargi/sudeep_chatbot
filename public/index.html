Privacy & Security Architecture

Browser-Specific Storage: By default, all conversation titles and message histories are persisted locally in your browser’s isolated localStorage. They are never sent to external tracking servers or third-party analytics.

Server-Side Secret Management: AI provider API keys (Google Gemini / OpenAI) are secured exclusively inside server-side environment variables and are never transmitted to browser clients.

Input Sanitization: All user inputs and assistant markdown streams undergo strict sanitization with DOMPurify to neutralize script injection risks (XSS).

Data Minimization: No user cookies, tracking pixels, or identifying telemetries are collected.
